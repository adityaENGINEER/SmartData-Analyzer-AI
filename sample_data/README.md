# Sample Datasets for DataDoctor AI

This directory contains test datasets demonstrating various data quality challenges:

1. `sample_sales_dirty.csv`:
   - Contains missing values in numerical and categorical columns.
   - Contains duplicated rows.
   - Contains text formatting inconsistencies (leading/trailing whitespace).
   - Contains statistical outliers in revenue and quantities.
   - Contains numbers formatted as text.

You can load these datasets directly into the **DataDoctor AI** web app or use the "Load Built-in Sample Dataset" button on the Overview page.
